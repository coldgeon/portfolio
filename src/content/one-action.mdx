## 문제 해결

<CaseStudy number="01" title="앱은 정상인데 외부 접속이 안 되는 문제">

**문제** · 동료가 Ingress의 보안그룹 생성 권한 오류(403)를 확인했습니다.

**조치** · IAM 조건을 보완하고 지정 범위의 허용·거부를 검사했습니다.

**결과** · ALB 생성과 외부 HTTP 200 응답을 확인했습니다.

</CaseStudy>

<CaseStudy number="02" title="노드 수용량과 데이터 보존 기반 마련">

**문제** · 운영 도구를 추가할 서버 용량과 저장 기반이 필요했습니다.

**조치** · EKS 노드를 2→3대로 확장하고 EBS CSI·gp3 저장소를 구성했습니다.

**결과** · 3노드 Ready와 시험 Pod 교체 후 파일 보존을 확인하고, 동료의 모니터링 설치를 지원했습니다.

</CaseStudy>

<CaseStudy number="03" title="로컬 환경의 알림을 중앙 API에 연결">

**문제** · 로컬에서 EKS 내부 주소에 접근할 수 없고, 첫 HTTPS 경로는 503으로 실패했습니다.

**조치** · API Gateway → VPC Link → 내부 ALB 경로로 수정하고 토큰 적용 도구·인증 검사를 마련했습니다.

**결과** · 경로를 검증한 뒤 동료의 실제 로컬 알림 수신으로 연결했습니다.

</CaseStudy>
