<CaseStudy number="01" title="Cloud Run 메모리 초과 대응">

**문제** · 512MiB 제한 초과로 역할극 stream이 멈췄습니다.

**조치** · 메모리 1GiB 조정, 실행 시 uv sync 제거와 동시 실행 수 축소를 적용했습니다.

**결과** · 실행 환경을 조정하고 전체 흐름 4회 이상 실행 기록을 확인했습니다.

</CaseStudy>

</CaseStudy>
