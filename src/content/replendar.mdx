## 개발·협업 사례

<CaseStudy number="01" title="Web 파트의 개발 흐름 조율">

**필요한 일** · 여러 개발자의 일정·코드·API 변경을 같은 기준으로 관리해야 했습니다.

**내 역할** · 초기 세팅·일정 조율·PR 리뷰를 맡고 Notion으로 API 명세·회의 결정사항을 공유했습니다.

**결과** · 공동 저장소와 협업 문서를 기준으로 Web 파트 개발을 운영했습니다.

</CaseStudy>

<CaseStudy number="02" title="로그인·개인화·화면 인터랙션 구현">

**필요한 일** · 사용자 인증과 화면 설정·서버 데이터를 연결해야 했습니다.

**내 역할** · 카카오 로그인·API 연동, 전역 테마·지연 로딩·스크롤 사이드바를 구현했습니다.

**결과** · 로그인과 개인화된 과제 관리 화면을 연결했습니다.

</CaseStudy>

<CaseStudy number="03" title="프론트엔드 결과물 배포">

**내 역할** · GitHub Pages 배포와 서비스 도메인 연결을 담당했습니다.

**결과** · 프로젝트 완료 시점에 웹 결과물을 배포했습니다. 현재 백엔드 서버 이용 기간이 끝나 당시 화면과 공개 저장소로 구현을 소개합니다.

</CaseStudy>
